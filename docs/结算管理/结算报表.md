## 一、模块概述

结算报表提供结算数据的查询与导出功能，分三个 Tab：**赛事报表**（近期汇总指标与图表）、**归档查询**（近 1 年内详细记录）、**历史查询**（1 年以上冷归档）。

- 使用者为结算主管、结算员以及**运营人员**（运营人员仅有此页面的查询 + 导出权限）。
- 页面顶部提供**导出 CSV**、**导出 Excel**、**刷新**三个全局按钮。
- 每个功能按四点写：**① 功能　② 逻辑定义　③ 操作后体现　④ 备注 / 权限**。

---

## 二、全局操作

| 按钮 | 功能 |
|------|------|
| 导出 CSV | 将当前激活 Tab 的查询结果导出为 CSV 文件 |
| 导出 Excel | 将当前激活 Tab 的查询结果导出为 Excel 文件 |
| 刷新 | 重新拉取当前激活 Tab 的数据 |

## 三、赛事报表 Tab

- **① 功能**：展示选定时间区间内的结算汇总指标和图表，快速掌握近期结算全貌。
- **② 逻辑定义**：

  **查询条件**：日期区间（手动输入或快捷选择），快捷选项：今天 / 昨天 / 本周 / 近7日 / 本月，互斥激活。

  **图表区（两行）**：

  第一行：
  - **结算赛事数柱状图**：近 7 日每日结算场数柱状图，今日用深色高亮，横轴显示日期，纵轴为场数。
  - **总注单数环形图**：展示单关 vs 串关注单数量与占比（%），中心显示总注单数。

  第二行：
  - **资金构成横向进度条**：三行进度条展示总投注额（100% 基准）→ 派彩额（占比即 RTP）→ 平台盈亏（占比即盈利率）；每行标注金额和百分比。
  - **投注人数卡片**：显示去重投注人数和人均投注额。

  **每日结算指标明细表**：

  | 列名 | 说明 |
  |------|------|
  | 日期 | 具体日期 |
  | 投注额 | 当日总投注金额 |
  | 投注人数（去重） | 当日投注用户去重数 |
  | 派彩 | 当日总派彩金额（橙色显示）|
  | 盈亏 | 当日平台盈亏 = 投注额 − 派彩（正值绿色，负值红色）|
  | 盈利率 | 盈亏 ÷ 投注额（%）|

  表格底部**合计行**：投注额、派彩、盈亏为周期内累计合计；投注人数合计为周期内**去重统计**，不等于每日数字相加。

- **③ 操作后体现**：修改日期区间后点「刷新」或自动触发，图表和明细表同步更新。
- **④ 备注 / 权限**：结算主管 / 结算员 / 运营人员均可访问。

## 四、归档查询 Tab（近 1 年）

- **① 功能**：查询近 1 年内已结算赛事的实际结算结果，含终场比分、盘口数、派彩、结算人员等详细字段。
- **② 逻辑定义**：

  **查询条件**：

  | 条件 | 说明 |
  |------|------|
  | 日期（近1年） | 日期区间，范围限近 1 年内，超出范围日期不可选 |
  | 联赛 | 下拉，默认全部联赛 |
  | 操盘员 | 下拉，默认全部 |
  | 结算来源 | 下拉：全部 / 数据源结算 / 本地结算 |
  | 搜索框 | 搜索赛事ID / 球队名 / 盘口BT编号 |

  点击「查询」按钮触发查询。

  **结果表格列**：

  | 列名 | 说明 |
  |------|------|
  | 赛事 | 联赛标签 + 主客队名 |
  | 最终比分 | 终场比分（加粗）|
  | 盘口数 | 本场结算的盘口总数 |
  | 注单数 | 本场总注单数 |
  | 投注额 | 本场总投注金额 |
  | 派彩 | 本场总派彩金额（橙色）|
  | 盈亏 | 本场平台盈亏（正值绿色，负值红色）|
  | 结算来源 | 数据源 / 本地（小字标签）|
  | 结算人员 | 负责本场结算的人员姓名 |
  | 结算时间 | 赛事结算完成的时间 |

  表格顶部显示查询命中总场数（如「共 1,820 场」）。

- **③ 操作后体现**：点「查询」后列表刷新；导出按钮导出当前查询条件下的全量结果。
- **④ 备注 / 权限**：结算主管 / 结算员 / 运营人员均可访问。

## 五、历史查询 Tab（1 年以上）

- **① 功能**：查询 1 年前的结算数据（冷归档存储），字段结构与归档查询完全一致，查询响应速度可能略慢。
- **② 逻辑定义**：

  **查询条件**：与归档查询相同（日期区间限 1 年以上，即最晚截止日期为 1 年前）。

  **结果表格列**：与归档查询完全一致（赛事 / 最终比分 / 盘口数 / 注单数 / 投注额 / 派彩 / 盈亏 / 结算来源 / 结算人员 / 结算时间）。

  **数据留存期限**：**暂定，待合规 / 法务最终确认**；留存期限内的历史数据均可查询，超出留存期限的数据不再保留。

  冷存储查询响应可能有延迟，查询提交后显示加载状态，返回结果前不可重复提交。

- **③ 操作后体现**：点「查询」后显示加载状态，结果返回后渲染列表；导出按钮导出当前查询条件下的全量结果。
- **④ 备注 / 权限**：结算主管 / 结算员 / 运营人员均可访问。

## 六、字段说明

| 字段 | 说明 |
|------|------|
| 盈亏 | 平台盈亏 = 投注额 − 派彩额；正值表示平台盈利（绿色），负值表示平台亏损（红色）|
| 盈利率 | 盈亏 ÷ 投注额，表示平台从每笔投注中保留的比例 |
| RTP（派彩率）| 派彩额 ÷ 投注额，即用户实际获得的回报比例；RTP + 盈利率 = 100% |
| 结算来源 | 数据源结算：L1 由 IM 直接推送结果；本地结算：L2/L3/L4 由系统规则或人工处理 |
| 投注人数（去重）| 同一用户多次投注只计一次；周期合计行为跨日期去重，不等于每日数字相加 |

## 八、验收要点

| 编号 | 验证内容 | 预期结果 |
|------|----------|----------|
| 1 | 赛事报表合计行投注人数 | 合计行为周期内去重人数，不等于每日数字相加；备注文字说明此规则 |
| 2 | 归档查询日期范围限制 | 最早可选日期为 1 年前，超出范围的日期不可选 |
| 3 | 历史查询日期范围限制 | 最晚截止日期为 1 年前；在留存期限内的数据可查，超出期限的数据不返回 |
| 4 | 历史查询冷存储响应 | 查询提交后显示加载状态，结果返回前不可重复提交；结果慢于归档查询属正常现象 |
| 5 | 运营人员访问结算报表 | 可正常访问三个 Tab 并执行查询和导出；无法访问结算列表和结算详情 |
| 6 | 导出按钮范围 | 导出内容为当前 Tab 当前查询条件下的完整结果，而非仅当前页 |
| 7 | 资金构成进度条盈亏计算 | 平台盈亏 = 总投注额 − 派彩额；盈利率 + RTP = 100% |
