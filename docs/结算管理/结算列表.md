## 一、模块概述

结算列表是结算管理的**任务总览页**，以赛事为单位展示所有待结算 / 已结算 / 异常 / 已取消赛事，供结算人员快速定位并进入结算详情处理。同时提供注单视图，便于按注单维度查询。

- 页面由**左侧筛选栏**与**主内容区**组成。
- 主内容区分为**赛事视图**（默认）和**注单视图**两种展示模式。
- 每个功能按四点写：**① 功能　② 逻辑定义　③ 操作后体现　④ 备注 / 权限**。

## 二、名词定义

| 术语 | 含义 |
|------|------|
| 常规赛事 | 有明确开始时间和终场结果的赛事 |
| 冠军赛事 | 长期盘口，如夺冠 / 晋级 / 最佳球员等 Outright 类型 |
| 待结算 | 赛事已结束但盘口尚未全部完成结算 |
| 已结算 | 赛事所有盘口均已结算完毕 |
| 异常 | 赛事发生腰斩 / 取消 / 延期 / 数据错误等特殊情况 |
| 已取消 | 赛事被取消，全部注单退款 |
| 腰斩 | 比赛中途强制终止；已完成时段按比分结算，未完成时段退款 |
| 驳回 | 将已结算赛事回退为待结算状态；距最新结算时间 ≤ 24h（UTC）方可操作 |
| 赛果变化 | IM 推送了与当前已结算赛果不同的新赛果，需人工处理二次结算 |

## 四、左侧筛选栏

- **① 功能**：提供运动类型多选和赛事结算状态单选两个筛选维度，收敛主列表展示范围。
- **② 逻辑定义**：运动类型点击「⚙️」触发多选弹窗，可多选，默认全选；确认后按钮旁显示已选概要（如「全部运动」或具体运动类型）。赛事结算状态为单选单选组，各状态旁显示当前匹配数量（全部 / 待结算 / 已结算 / 异常 / 已取消）。
- **③ 操作后体现**：主列表即时按所选条件过滤。
- **④ 备注 / 权限**：结算主管和结算员均可操作。

## 五、工具栏

### 5.1 赛事类型 Tab

- **① 功能**：按数据源类型区分常规赛事与冠军赛事两种赛事类型。
- **② 逻辑定义**：常规赛事（默认激活）和冠军赛事各自显示场数数量；切换后列表完全替换为对应类型。
- **③ 操作后体现**：Tab 高亮切换，列表内容随之变更。
- **④ 备注 / 权限**：所有角色可见。

### 5.2 视图切换

- **① 功能**：在赛事视图和注单视图之间切换。
- **② 逻辑定义**：两种视图互斥，赛事视图为默认展示。
- **③ 操作后体现**：切换后主内容区完全替换为对应视图的列表结构。
- **④ 备注 / 权限**：所有角色可见。

### 5.3 联赛筛选

- **① 功能**：按联赛过滤赛事列表。
- **② 逻辑定义**：下拉选项仅展示当前日期区间内有赛事的联赛，随开赛时间筛选联动刷新。默认「全部联赛」。
- **③ 操作后体现**：列表即时过滤。
- **④ 备注 / 权限**：所有角色可见。

### 5.4 开赛时间筛选

- **① 功能**：按开赛时间区间筛选赛事，精确到秒。
- **② 逻辑定义**：日期时间输入框（精确到秒）+ 快捷按钮（今天 / 昨天 / 本周），快捷按钮点击后自动填充对应区间；快捷按钮互斥激活。
- **③ 操作后体现**：列表按所选时间区间过滤；联赛下拉随之联动刷新。
- **④ 备注 / 权限**：所有角色可见。

### 5.5 人员配置

- **① 功能**：打开结算主管专属的人员配置浮窗（详见 §九）。
- **② 逻辑定义**：点击「👥 人员配置」按钮展开浮窗；按钮仅对结算主管显示。
- **③ 操作后体现**：浮窗出现在页面内可拖动位置。
- **④ 备注 / 权限**：**仅结算主管**可见。

### 5.6 💡 结算模块说明

- **① 功能**：展示结算自动化分层（L1-L4）说明，供结算人员随时查阅。
- **② 逻辑定义**：点击「💡 说明」按钮弹出说明弹窗，内容如下：
  - L1：数据源盘口 + IM 已推送终态 → 无需人工介入，本地直接派彩
  - L2（自动开关=开）：可操盘盘口 + IM 已推送比分 → 无需人工介入，系统自动结算
  - L2（自动开关=关）：同上 → 系统预填结果，**需结算人员确认**
  - L3：可操盘盘口 + IM 未推送比分 → **结算人员补录比分**，系统推算
  - L4：IM 无法覆盖的约 40 种小众玩法 → **结算人员逐盘口手动选择结果**
- **③ 操作后体现**：弹窗展示说明内容，点 × 关闭。
- **④ 备注 / 权限**：所有角色可见。

## 六、赛事视图

### 6.1 表内筛选工具栏

位于列头上方，提供两个筛选控件：
- **全部结算人员**（下拉）：真实过滤赛事卡片，仅显示对应结算人员负责的赛事；默认「全部结算人员」。
- **搜索框**：搜索赛事ID / 盘口ID / 球队名，即时过滤。

### 6.2 表格列定义

| 列名 | 说明 |
|------|------|
| 复选框 | 全选/单选，勾选后可执行批量操作 |
| 赛事ID | 唯一标识，可点击跳转结算详情 |
| 对阵信息 | 国旗 + 主客队名；含串关标签（紫色）|
| 比分 | 终场比分 + 比赛状态（终场/腰斩/已取消等）|
| 开赛时间 | 精确到分 |
| 结算时间 | 已结算显示绿色时间；待结算显示「—」|
| 盘口结算 | 已结算盘口数 / 总盘口数（如 14/22）|
| 结算人员 | 负责本场的结算人员姓名，点击可触发分配弹窗 |
| 状态 | 详见 §6.3 状态标签规则 |
| 操作 | 详见 §6.3 操作按钮规则 |

### 6.3 状态标签与操作按钮对应规则

| 赛事状态 | 状态标签 | 附加标签 | 操作按钮 |
|----------|---------|---------|---------|
| 待结算 | 待结算（橙） | — | **结算**（→ 结算详情）|
| 待结算 + 驳回后 | 待结算（橙） | ⏱ 驳回窗口剩余 Xh Ym（橙） | **结算** |
| 待结算 + 赛果变化 | 待结算（橙） | ⚠️ 赛果变化 N（橙） | **结算** |
| 已结算 | 已结算（绿） | — | 详情 |
| 异常 · 腰斩暂缓 | 异常 · 腰斩暂缓 X'（红） | — | 详情（异常处理入口在结算详情，入口唯一）|
| 已取消 | 已取消（灰，行整体降低透明度） | — | 详情 |

**赛果变化标签说明**：当 IM 推送了与已结算赛果不同的新赛果时，系统**自动检测并打标**，N 为受影响盘口数；标签在结算人员完成二次结算后**自动清除**，不支持手动关闭，需人工进入详情页处理。

**驳回窗口倒计时**：驳回后待结算的赛事，附加「⏱ 驳回窗口剩余 Xh Ym」标签，每分钟更新一次。

### 6.4 赛事卡片日志条目

每张赛事卡片下方附有**最新一条操作日志**（时间 + 来源标签 + 内容），展示该赛事最近一次的操作或系统事件，便于快速了解当前处理进度，无需进入详情页。

来源标签类型：数据源（蓝）/ 人工（绿）。

### 6.5 分页器

显示「共 N 场赛事 | 显示 X-Y 条」；每页条数可选（10 / 20 / 50）；支持上一页/下一页。

## 七、注单视图

### 7.1 注单筛选工具栏

- **类型 Tab**：全部注单 / 单关 / 串关，各 Tab 旁显示对应注单数量，互斥。
- **注单号搜索框**：搜索具体注单号。
- **赛事ID/球队名搜索框**：按赛事维度搜索（独立输入框）。

### 7.2 注单列表列定义

| 列名 | 说明 |
|------|------|
| 用户ID | 下注用户唯一标识 |
| 类型 | 单关（蓝标签）/ 串关（紫标签）|
| 注单号 | 注单唯一编号，含📋复制按钮 |
| 投注内容 | 赛前/滚球阶段标签 + 赛事名称 + 玩法 + 选项 + 赔率 + 开赛时间 |
| 投注额 | 本笔注单金额 |
| 预计派彩 | 按当前赔率计算的潜在派彩金额 |
| 结算结果 | 已结算注单显示赢/输/退还等结果；待结算显示「—」|
| 状态 | 待结算 / 已结算 / 已退款 / 异常 |
| 操作 | 结算（单注结算弹窗）/ 退款 |

### 7.3 串关注单展开

串关注单行可展开，显示所有关联腿的详情：腿序号、赛事名称、玩法/选项/赔率、该腿状态（已结算/待结算/取消）。关联赛事中有腰斩/延期/异常时，注单行顶部显示红色警示横幅提示结算人员。

### 7.4 注单结算弹窗

点击注单行「结算」按钮触发，按基准分分组展示各选项结算结果，支持单组和多组基准分两种模式，结算人员确认结果后点「确认结算」执行派彩。

### 7.5 注单退款弹窗

按币种二次确认退款金额后执行，展示退款金额明细（CNY / USDT / VND 分行展示）。

## 八、批量操作

- **① 功能**：勾选多场赛事后批量执行分配结算人员操作。
- **② 逻辑定义**：勾选一场或多场赛事后底部出现批量操作浮动栏，显示「已选 N 场赛事」计数。批量分配会覆盖所选赛事的原结算人员；已结算/已取消赛事无结算任务，建议排除后再批量分配。
- **③ 操作后体现**：点「批量分配结算人员」→ 弹出批量分配弹窗（详见 §八.1）；点「取消选择」→ 浮动栏收起，勾选清空。
- **④ 备注 / 权限**：批量分配仅结算主管可操作，结算员触发时 Toast 提示无权限。

### 8.1 批量分配结算人员弹窗

- **① 功能**：为多场所选赛事统一指定一名结算人员。
- **② 逻辑定义**：弹窗展示已选场数，提供结算人员下拉选择（单一人员，不分阶段）；支持「清除分配」选项还原为未分配状态。提示：批量操作会覆盖原结算人员，已结算/已取消赛事建议排除。
- **③ 操作后体现**：点「确认」→ Toast 提示「批量分配成功：共 N 场赛事，结算人员 → XXX」；各赛事卡片「结算人员」列即时更新。
- **④ 备注 / 权限**：**仅结算主管**可操作。

### 8.2 单赛事分配结算人员弹窗

- **① 功能**：为单场赛事指定结算人员。
- **② 逻辑定义**：点击赛事卡片「结算人员」列触发，弹窗展示当前已分配人员，提供人员下拉选择。
- **③ 操作后体现**：确认后卡片「结算人员」列即时更新；Toast 提示分配成功。
- **④ 备注 / 权限**：**仅结算主管**可操作。

## 九、人员配置浮窗（结算主管专属）

- **① 功能**：实时查看当前所有结算员的在线状态和负责场数，便于结算主管统筹调度。
- **② 逻辑定义**：可拖动浮窗，默认显示在页面左下角。每位结算员显示：姓名、在线/离线状态（绿/灰点）、当前负责待结算场数。顶部统计行显示总人数（在线/离线）。支持「仅看在线」Toggle、「排序」切换（按场数 / 按姓名）、「⟳ 刷新」、「─ 最小化」（折叠正文只留标题栏）、「✕ 关闭」（关闭后从工具栏「人员配置」按钮重新打开）。
- **③ 操作后体现**：浮窗数据随结算人员分配变更实时更新；各操作即时响应。
- **④ 备注 / 权限**：**仅结算主管**可见，结算员视角下完全不显示。
