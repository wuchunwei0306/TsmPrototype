## 一、模块概述

操盘详情是操盘手对**单场赛事**执行精细化盘口操作的核心作业页面。进入方式：从操盘列表点击「操盘」按钮跳转。

- 页面由三栏组成：**左侧赛事列表面板**（可折叠）、**中间操盘区**（赛事信息头 + 盘口工具栏 + 盘口列表）、**右侧监控面板**（可折叠）。
- 底部有**快捷键栏**，中央有滑出式**快捷操作面板**（赛事级批量操作）。
- 赔率制式（港赔 / 欧赔）与操盘列表共用同一全局开关。
- 每个功能按四点写：**① 功能　② 逻辑定义　③ 操作后体现　④ 备注 / 权限**。

## 二、名词定义

| 术语 | 含义 |
|------|------|
| 可操盘口 | 让球、大小等支持本地赔率调整的玩法盘口（与「只读盘口」区别） |
| 只读盘口 | 角球、波胆等默认全量飞单 IM、不支持本地手动调整的盘口 |
| 数据源开关 | 控制该玩法 / 线是否跟随 IM 自动更新赔率 |
| 飞单 | 注单是否同步发给 IM；开启 = 注单同步发送 IM（对冲风险）；关闭 = 注单仅本地自收（平台自承风险） |
| RTP | Return to Player，返奖率；该页面仅展示，不可编辑 |
| 本地赔率 | 操盘手在本系统设置的赔率，数据源关闭后可手动调整 |
| IM 赔率 | 来自 IM 数据源的实时参考赔率 |
| 初始赔率 | 本场赛事上架时的起始赔率，全程只读 |
| 偏离值 | 本地赔率与 IM 赔率的差值（可手动调整） |
| 风险注单 | 触发风控规则的注单，需操盘手人工审核 |
| 玩法级 / 线级 / 选项级 | 盘口状态控制的三个作用域，从粗到细依次作用于整个玩法、单条盘口线、单个投注选项 |

## 四、左侧赛事列表面板

- **① 功能**：以分组卡片形式展示当前操盘手可见范围内的赛事，支持快速切换查看不同赛事的盘口详情。提供赛事搜索框。面板可整体折叠，折叠后以运动队缩写图标列展示。
- **② 逻辑定义**：赛事按进程分组——滚球（含中场休息）、即将开赛、赛前，各组可独立展开/收起。每张赛事卡片展示：比赛阶段标签、赛事ID、主客队名、当前比分（赛前显示「-:-」）、风险敞口金额、单边占比（**不展示单边累计**）。有风险告警的赛事卡片左侧带红色色条，有警告的带橙色色条。搜索框即时过滤赛事名/队名。
- **③ 操作后体现**：点击赛事卡片 → 中间操盘区切换为该赛事的盘口；当前选中卡片高亮蓝色边框。
- **④ 备注 / 权限**：所有角色可见。

## 五、赛事信息头

- **① 功能**：纯展示当前选中赛事的基本信息与实时统计数据，不含任何操作按钮。
- **② 逻辑定义**：
  - **左侧**：主队名、客队名、实时比分（蓝色大字）、赛事阶段标签（滚球/赛前/中场等）+ 比赛时间（如「下半场 67'」）。
  - **中间**：赛事ID、联赛名称 + 联赛ID、联赛等级。
  - **右侧**：投注额（当前该赛事总投注额）、盈亏（正绿负红）、风险敞口（超限时红色）、风险注单数（有待审核时橙色警示）。
- **③ 操作后体现**：数据随比赛进程与投注实时刷新。
- **④ 备注 / 权限**：所有角色只读。

## 七、盘口卡片

每张盘口卡片代表一个玩法的完整盘口，由卡片头、卡片体（表格/矩阵）、投注分布条、卡片脚四部分组成。

### 7.1 卡片头

| 元素 | 说明 |
|------|------|
| 玩法名 | 如「全场让球」「波胆」 |
| 阶段标签 | 滚球（红）/ 赛前（蓝）等 |
| BT 编号 | 如「BT:1」「BT:6」 |
| RTP | 返奖率，**仅展示，不可编辑** |
| 状态标签 | ● 开盘 / 👁 已隐藏 / 🔒 已锁定 / 关盘 |
| 数据源开关（可操盘口） | 控制该玩法是否跟随 IM 自动更新赔率；开启时本地赔率为只读 |
| 飞单开关（可操盘口） | 控制该玩法注单是否同步发送 IM；仅可操盘口显示此开关（见 §八） |
| 玩法级状态控制 | 「👁 隐藏 / 取消隐藏」「🔒 锁定 / 解锁」，作用于该玩法所有盘口线和选项（互斥显示：已隐藏时显示「取消隐藏」，已锁定时显示「解锁」）|
| 日志按钮 | 📋，打开该玩法的操盘日志弹窗 |
| 展开/收起按钮 | ▼ / ▶，控制卡片体显示/隐藏 |

### 7.2 卡片体 — 四种渲染方式

#### 多线表格（让球 / 大小等多线玩法）

表头列：盘口线 | 选项 | IM 赔率 | 初始赔率 | 本地赔率 | 偏离值 | 货量/注单数 | 占比 | 风险。

**盘口线单元格**（rowspan 跨行）含：
- RTP 显示（只读）
- 主线/副线标签（主线橙色「主」标）
- 线值（如「-0.5」「2.5」）
- 该线小计（货量 + 敞口）
- 线级状态标签
- **线级控制**：「🔗 源」（线级数据源开关）+ 「👁 隐藏/取消隐藏」+ 「🔒 锁定/解锁」小图标按钮

**本地赔率列**：数据源开启时只读，点击出现「数据源只读提示弹窗」（说明需先关闭数据源才能手动编辑）；数据源关闭后双击赔率数字进入输入态。赔率变动显示 ↑↑（绿）/ ↓↓（红）趋势箭头，变动时闪烁动画。

**偏离值列**：点击可手动输入，表示本地赔率与 IM 赔率的差值；正数绿色，负数红色。

**风险列**：显示该选项的风控触发次数；有触发时红色数字可点击，弹出「风险触发记录」弹窗（详见 §十）；无触发时显示「—」。

表格底部有合计行（显示总线数、总货量/注单数、汇总占比）。

#### 单线表格（独赢 / 单双 / 双重机会等）

表头列：选项 | 初始赔率 | 本地赔率 | IM 赔率 | 偏离值 | 货量/注单数 | 占比 | 风险。

每行选项旁有**选项级控制**：「👁 隐藏/取消隐藏」「🔒 锁定/解锁」小图标按钮，仅作用于该选项。

#### 矩阵视图（波胆 BT6 / 半全场 BT9）

**波胆（BT6）**：5×5 网格，行=主队进球数（0~4+），列=客队进球数（0~4+）。每个单元格显示：比分 + 赔率（只读或可编辑）+ 投注额/注单数 + 风险敞口。

**半全场（BT9）**：3×3 网格，行=半场结果（主/和/客），列=全场结果（主/和/客）。

矩阵单元格特殊状态：
- 当前实时比分 → 绿色边框高亮
- 敞口超限 → 红色字体标红
- 不可能出现的比分（如当前 2-1 时不可能出现 0-0）→ 灰显不可操作
- Hover 时出现该格的「👁」「🔒」控制按钮

矩阵底部有图例（有投注 / 高风险 / 当前比分的色块说明）和全局敞口统计。

#### LongList 列表（总进球 BT7 等多选项玩法）

顶部工具栏含：排序下拉（默认顺序 / 赔率低→高 / 赔率高→低 / 货量高→低 / 风险高→低）、过滤选项（显示零货量 / 仅高赔率 >5.0）、统计信息（共 N 个选项 / 总货量）。

表格与单线表格相同列结构，可滚动，每行选项旁有选项级控制按钮。

### 7.3 投注分布条

位于卡片体和卡片脚之间，展示各选项的投注占比进度条：
- 二选项（让球/大小）：双色进度条（蓝/红）+ 各选项名称和占比百分比。
- 三选项（独赢）：三段进度条（蓝/灰/红）+ 主胜/和局/客胜占比。

### 7.4 卡片脚

展示该玩法汇总数据：货量（总注单数 / 总金额）、已接受/拒绝数（拒绝数红色）、风险注单数。

## 八、飞单机制

- **① 功能**：控制可操盘口的注单是否同步发送给 IM，决定平台的风险承担方式。
- **② 逻辑定义**：

| 状态 | 行为 | 风险归属 |
|------|------|---------|
| 飞单开启 | 每笔注单同时生成两份：一份按 IM 原始赔率发送 IM 系统结算；一份按本地调整赔率在本地记录；两者差价由平台承担或获利 | 部分对冲给 IM |
| 飞单关闭 | 注单仅在本地自收，不发送 IM | 风险全由平台承担 |

  - **适用范围**：仅「可操盘口」（让球、大小等）支持飞单开关；角球、波胆等「只读盘口」默认飞单至 IM 且无法关闭。
  - **层级**：分**赛事级**和**玩法级**两层。赛事级开关（位于底部快捷操作面板）同步作用于所有可操盘口；玩法级开关在各盘口卡片头单独控制，可覆盖赛事级设置。
  - 关闭数据源（赔率转手动）时，飞单开关仍独立工作；两者互不联动。

- **③ 操作后体现**：Toggle 状态更新；Toast 提示「[玩法名/赛事级] 飞单已开启（IM+本地双注单）/ 已关闭（仅本地自收）」。
- **④ 备注 / 权限**：操盘主管和操盘员均可操作。

## 九、右侧监控面板

面板可整体折叠，折叠后以图标列展示（⚠️ 风险注单 / 💰 最近投注），点击图标展开面板并跳转到对应区域。

### 9.1 风险注单

- **① 功能**：实时展示当前赛事中触发风控规则、需要操盘手人工审核的注单，支持逐笔或全量接受/拒绝。
- **② 逻辑定义**：每笔风险注单显示：注单金额（橙色）、下注时间、投注详情（玩法 + 选项 + 赔率）。顶部角标显示待审核总数。底部有「全部接受」「全部拒绝」两个快捷按钮。
- **③ 操作后体现**：
  - 点「✓ 接受」→ 该注单状态变为已接受，从待审核列表移除，计入货量统计；
  - 点「✗ 拒绝」→ 该注单状态变为已拒绝，从待审核列表移除；
  - 「全部接受」/ 「全部拒绝」→ 批量处理当前所有待审核注单。
- **④ 备注 / 权限**：区域可独立折叠；所有角色可操作。

### 9.2 最近投注

- **① 功能**：实时流水展示当前赛事的最新投注记录，支持按状态筛选查看。
- **② 逻辑定义**：顶部 Tab 筛选：「已接受/待审」（默认）/ 「全部」。投注流中每笔记录显示：金额、时间、投注详情（玩法+选项+赔率）、状态标签（已接受绿色 / 待审核橙色）。底部有「已拒绝」折叠区，默认收起，点击展开，每笔已拒绝注单显示拒绝原因（如「超出单注限额」「赔率已变更」「风控拦截」「盘口已关盘」）。
- **③ 操作后体现**：新注单实时插入列表顶部；接受/拒绝操作后状态标签即时更新；已拒绝区数量角标随之变化。
- **④ 备注 / 权限**：区域可独立折叠；所有角色只读（审核操作在风险注单区完成）。

## 十、风险触发记录弹窗

- **① 功能**：查看盘口表格中「风险」列某选项/线的具体风控触发详情。
- **② 逻辑定义**：点击风险列红色数字触发。弹窗展示：触发的玩法 + 选项名称、触发次数、每条触发记录（触发时间、触发规则名称、触发值）。与操盘列表的风控触发计数为同一套数据。
- **③ 操作后体现**：弹窗展示触发详情，点 × 关闭。
- **④ 备注 / 权限**：所有角色可查看。

## 十一、操盘日志弹窗（玩法级）

- **① 功能**：查看当前赛事某一玩法的操作历史记录。
- **② 逻辑定义**：点击盘口卡片头的「📋」按钮触发。日志结构与操盘列表的操盘日志弹窗一致（时间 / 操作类型 / 盘口 / 操作详情 / 操作人 / 来源），但默认范围限定在该玩法。筛选条件相同（时间范围 / 操作类型 / 操作来源 / 盘口ID），支持导出，支持分页。
- **③ 操作后体现**：点「查询」刷新；点「导出」下载。
- **④ 备注 / 权限**：所有角色可查看。

## 十二、底部快捷操作面板

- **① 功能**：对当前赛事所有可操盘口执行**赛事级**批量快捷操作，以及快速切换赛事级全局开关。
- **② 逻辑定义**：通过底部快捷键栏中央的「快捷操作」按钮触发，从底部向上滑出浮层面板。面板分以下功能组：

| 功能组 | 内容 |
|--------|------|
| 当前状态 | 展示当前赛事盘口整体状态（开盘 / 已隐藏 / 已锁定 / 已关盘）|
| 批量状态操作 | 「👁 批量隐藏 / 取消隐藏」「🔒 批量锁定 / 解锁」，作用于该赛事所有盘口；互斥显示：已隐藏时显示「取消隐藏」，已锁定时显示「解锁」 |
| 赛事操作 | 显示当前上架状态 + 「⬇️ 下架」按钮（→ 下架确认弹窗）/ 「⬆️ 上架」按钮（→ 上架确认弹窗）；两者互斥显示 |
| 数据源 | 「跟随 IM」Toggle 开关，赛事级，同步作用于所有可操盘口的数据源开关 |
| 飞单 | 赛事级飞单开关，同步作用于所有可操盘口的飞单开关（见 §八）|
| 工具 | 「📋 日志」（打开赛事级操盘日志弹窗）、「📈 同步」（将当前 IM 赔率同步应用到所有手动模式的盘口）|

- **③ 操作后体现**：批量操作后所有相关盘口卡片状态标签即时更新；Toast 提示操作结果。点「×」或再次点击底部按钮收起面板。
- **④ 备注 / 权限**：所有角色可操作；下架 / 上架权限与操盘列表相同。

## 十三、底部快捷键栏

固定在页面底部，展示常用键盘快捷键提示：

| 快捷键 | 功能 |
|--------|------|
| Tab | 切换选中盘口 |
| H | 隐藏当前选中盘口 |
| L | 锁定当前选中盘口 |
| F1 | 全部锁定（赛事级）|
| F3 | 搜索盘口 |

中央为「快捷操作」触发按钮（详见 §十二）。

## 十四、盘口状态体系

操盘详情中的盘口状态控制分三个作用域，从粗到细：

```
玩法级（整个玩法所有线/选项）
  └── 线级（多线玩法中的单条盘口线，含该线下所有选项）
        └── 选项级（单个投注选项，如「主胜」「大 2.5」）
```

**状态说明：**

| 状态 | 含义 | 颜色 |
|------|------|------|
| 开盘（Open） | 正常接受投注 | 绿色 |
| 隐藏（Hidden） | C 端不可见，停止接受新投注；可随时取消隐藏恢复 | 橙色 |
| 锁定（Locked） | 停止接受投注，需人工解锁；比数据源恢复更严格 | 红色 |
| 关盘（Closed） | 关闭盘口，不可恢复（结算后状态）| 灰色 |

**互斥显示规则**：隐藏按钮与取消隐藏按钮、锁定按钮与解锁按钮，根据当前状态互斥显示其中一个。

**级联规则**：玩法级隐藏/锁定作用于该玩法所有线和选项；线级操作只影响该线；选项级只影响该选项。上级锁定时下级状态控制按钮不可用（禁用态）。

## 十五、数据源开关与赔率编辑规则

| 数据源状态 | 本地赔率 | 偏离值 | 线级 RTP |
|-----------|---------|--------|---------|
| 开启（跟随 IM） | 只读，不可编辑；点击弹出提示弹窗 | 只读 | 只读 |
| 关闭（手动模式） | 双击进入编辑态（输入框），可直接修改 | 点击可编辑 | 只读（RTP 全程只读）|

**数据源只读提示弹窗**（数据源开启时点击赔率触发）：说明「当前赔率由数据源自动管理，需先关闭数据源才能手动调整」，提供「关闭数据源」快捷按钮。

**手动模式视觉标识**：关闭数据源后，本地赔率列变为蓝色边框/背景，表示当前为手动控制状态。

## 十七、验收要点

| 编号 | 验证内容 | 预期结果 |
|------|----------|----------|
| 1 | 左侧赛事列表切换赛事 | 中间操盘区内容切换为对应赛事盘口，原赛事状态不受影响 |
| 2 | 数据源开启状态下点击本地赔率 | 弹出数据源只读提示弹窗，不进入编辑态 |
| 3 | 关闭数据源后双击赔率 | 赔率进入输入框编辑态，边框变蓝色 |
| 4 | 玩法级点击「隐藏」 | 该玩法所有盘口线/选项状态变为隐藏，卡片头状态标签更新为「已隐藏」，「隐藏」按钮切换为「取消隐藏」 |
| 5 | 线级点击「🔒」锁定某一条线 | 仅该线状态变为锁定，同玩法其他线不受影响；该线下选项的状态控制按钮变为禁用态 |
| 6 | 选项级点击「👁」隐藏某一选项 | 仅该选项状态变为隐藏，同线其他选项不受影响 |
| 7 | 飞单开关关闭 | Toast 提示「飞单已关闭（仅本地自收）」；注单不再发送 IM |
| 8 | 赛事级数据源开关关闭 | 所有可操盘口的数据源 Toggle 同步变为关闭状态；只读盘口（角球/波胆等）不受影响 |
| 9 | 赛事级飞单开关开启 | 所有可操盘口的飞单 Toggle 同步变为开启；只读盘口不受影响 |
| 10 | 风险注单点「✓ 接受」 | 该注单移出待审核列表，计入货量统计；角标数字减 1 |
| 11 | 风险注单点「全部拒绝」 | 所有待审核注单批量拒绝，待审核列表清空，角标归零 |
| 12 | 点击风险列红色数字 | 弹出风险触发记录弹窗，展示该选项的触发时间、规则名称和触发值 |
| 13 | 波胆矩阵当前比分单元格 | 对应单元格绿色边框高亮 |
| 14 | 快捷操作面板「批量隐藏」 | 该赛事所有盘口状态变为隐藏，各卡片状态标签即时更新 |
| 15 | RTP 字段 | 所有角色只可查看，点击不进入编辑态 |
| 16 | 「📈 同步」按钮 | 将所有当前处于手动模式（数据源关闭）的盘口赔率同步替换为当前 IM 赔率 |
