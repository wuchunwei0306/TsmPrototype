## 一、模块概述

风控日志用于查询历史风控告警的完整生命周期记录（触发 → 解除），供操盘主管复盘和审计使用。

- **仅操盘主管**可访问，运营人员无权查看，侧边栏导航对运营人员不显示此入口。
- 支持多维度筛选、行展开查看推送详情、导出 CSV。
- 每个功能按四点写：**① 功能　② 逻辑定义　③ 操作后体现　④ 备注 / 权限**。

---

## 二、名词定义

| 术语 | 含义 |
|------|------|
| 触发 | 风控告警事件产生，开始计时 |
| 解除 | 告警事件结束，分自动恢复（指标回落）和人工解除两种方式 |
| 持续时长 | 从触发到解除的时间跨度 |
| 高危级 | 告警级别最高档，需立即处理 |
| 推送记录 | 每次告警状态变更（触发/解除）产生的一条推送，含时间和操作人 |

## 三、页面结构

```
左侧统计栏（全量统计，不随筛选条件变化）
├── 进行中（未解除告警数）
├── 今日触发总数
└── 高危级数

右侧主内容区
├── 筛选栏
├── 操作栏（重置 + 导出 CSV）
└── 日志表格（含行展开）
```

---

## 四、左侧统计栏

- **① 功能**：展示当前风控告警的全局概览数据，帮助操盘主管快速掌握整体风控状态。
- **② 逻辑定义**：三个统计卡片始终展示全量数据，**不随右侧筛选条件变化**：进行中（当前仍处于告警状态的事件总数）、今日触发总数（今日全部告警触发次数）、高危级（今日高危级告警数量）。
- **③ 操作后体现**：数据实时刷新（新告警触发时自动更新）。
- **④ 备注 / 权限**：仅操盘主管可见。

---

## 五、筛选条件

- **① 功能**：多维度筛选日志列表，支持多条件 AND 组合查询。
- **② 逻辑定义**：

  | 筛选项 | 类型 | 选项 |
  |--------|------|------|
  | 操盘员 | 下拉单选 | 全部 / 指定操盘员 |
  | 告警类型 | 下拉单选 | 全部 / 单边超限 / 大额 / 延期超时 / 滚球未上架 / 数据源暂停 / 维护中 / 数据延迟 / 即将开赛未上架 / 比赛暂停 / 中立场 |
  | 级别 | 下拉单选 | 全部 / 高危 / 高 / 中 / 低 |
  | 状态 | 下拉单选 | 全部 / 进行中 / 已解除 |
  | 日期 | 日期选择器 | 精确到日 |
  | 搜索框 | 文字输入 | 搜索赛事名 / 联赛名 / 盘口 BT 编号 |

- **③ 操作后体现**：条件变化后列表即时收敛；点击「重置」→ 清空所有筛选条件，还原全量列表。
- **④ 备注 / 权限**：仅操盘主管可操作。

---

## 六、日志表格

- **① 功能**：以表格形式展示所有符合筛选条件的风控告警记录，支持行展开查看推送详情。
- **② 逻辑定义**：

  **表格列**：

  | 列名 | 说明 |
  |------|------|
  | 展开图标 | ▸（收起）/ ▼（展开），点击展开推送时间线 |
  | 状态 | 进行中（橙色）/ 已解除（灰色）|
  | 告警类型 + 级别色标 | 告警类型文字 + 右侧色标（高危红加粗 / 高红 / 中橙 / 低蓝）|
  | 关联赛事 | 赛事名称·联赛名称 + BT 标签（如「BT:1」）|
  | 操盘员 | 负责该赛事的操盘员姓名 |
  | 触发时间 | 告警触发的精确时间 |
  | 解除时间 | 告警解除的时间；进行中显示「—」|
  | 持续时长 | 触发到解除的时长；进行中显示累计时长（实时更新）|
  | 推送人 | 触发该告警的来源（系统自动 / 人工操作人姓名）|

  **级别色标规则**：

  | 级别 | 色标样式 |
  |------|---------|
  | 高危 | 红色加粗 |
  | 高 | 红色 |
  | 中 | 橙色 |
  | 低 | 蓝色 |

- **③ 操作后体现**：表格按触发时间倒序排列（最新在前）；进行中的记录置顶显示。
- **④ 备注 / 权限**：仅操盘主管可查看。

---

## 七、行展开（推送时间线）

- **① 功能**：展开单条告警记录，查看该告警事件完整的推送记录时间线。
- **② 逻辑定义**：点击行左侧展开图标（▸）触发展开，展开后图标变为（▼）；再次点击收起。时间线结构：

  | 时间线节点 | 内容 |
  |-----------|------|
  | 触发推送 | 时间 + 「系统自动触发」或「人工：操作人姓名」+ 触发值（如「单边占比 78%，超过阈值 70%」）|
  | 中间推送（若有多次变化）| 时间 + 操作人 + 变化说明 |
  | 解除推送 | 时间 + 「系统自动解除」或「人工：操作人姓名」+ 解除原因 |

- **③ 操作后体现**：展开区域在行下方展开，同时只能展开一行（展开新行时自动收起上一行）。
- **④ 备注 / 权限**：仅操盘主管可查看。

---

## 八、导出 CSV

- **① 功能**：将当前筛选条件下的全量日志导出为 CSV 文件，用于离线分析和审计。
- **② 逻辑定义**：点击右上角「⬇ 导出 CSV」按钮触发；导出范围为当前筛选条件下的全量记录（不受分页限制）；导出字段与表格列一致，不含展开的时间线详情。
- **③ 操作后体现**：弹出提示说明导出条数（如「共导出 128 条记录」），并自动下载 CSV 文件。
- **④ 备注 / 权限**：仅操盘主管可操作。
