## 一、模块概述

操盘列表是操盘系统的**日常作业主界面**，汇聚当前可见范围内的所有赛事，供操盘手执行上架、下架、分配操盘员、盘口状态监控等核心操作。

- 页面由三部分组成：**左侧运动类型导航栏**（可折叠）、**顶部筛选区**（四行）、**赛事数据表格**（含批量操作浮动栏）。
- 另含多个弹窗：上架确认、批量上架（逐场设置）、分配操盘手、下架确认、操盘日志、一键锁盘、一键解锁。
- 页面右上角有**告警通知中心**（Toast 三层架构 + 消息中心抽屉），以及主管专属的**人员配置浮窗**。
- 每个功能按四点写：**① 功能　② 逻辑定义（含查询范围）　③ 操作后体现　④ 备注 / 权限**。

## 二、名词定义

| 术语 | 含义 |
|------|------|
| 待上架 | 赛事已从数据源获取、尚未对 C 端开放投注 |
| 已上架 | 赛事已下发、C 端可投注（含隐藏状态） |
| 已下架 | 赛事曾上架后被主动下架，C 端不可见，已有注单不受影响 |
| 隐藏 | 上架后盘口对 C 端不可见，但内部状态为已上架；可随时取消隐藏 |
| 滚球 | 比赛进行中的实时盘，实时推送赔率 |
| 即将 | 距开赛 ≤10 分钟的赛前赛事 |
| 赛前 | 距开赛 >10 分钟的未开赛赛事 |
| 延期 | 比赛原定时间已过但尚未开赛的赛事 |
| 主管 / 风控 | 拥有分配操盘手、一键锁盘 / 解锁等高权限的角色 |
| 操盘员 | 普通操盘手，只能看到自己负责的赛事及基础操作 |
| BO | Best Of，如 BO3 表示三局两胜制（电竞常用） |
| IM | 数据源提供商，系统唯一数据源 |

## 四、左侧运动类型导航栏

- **① 功能**：按运动类型 + 联赛两级展示当前可见赛事的归类导航，支持折叠/展开侧边栏、搜索联赛/赛事名称、点击运动类型或联赛快速筛选主列表。顶部显示 IM 数据源连接状态（在线 / 离线 / 延迟）及延迟毫秒数。
- **② 逻辑定义**：运动类型旁的数字气泡为该运动当前可见范围内的赛事总数；若有滚球赛事，气泡标红；展开运动类型后显示该运动下的联赛列表，联赛旁显示该联赛赛事数。搜索框输入后实时过滤联赛/赛事名，Enter 或停止输入 800ms 后触发。
- **③ 操作后体现**：点击联赛 → 主列表只显示该联赛赛事；点击运动类型 → 主列表筛选该运动全部赛事；折叠后只显示图标，悬停可看运动类型名。
- **④ 备注 / 权限**：所有角色可见。

## 五、顶部工具栏

### 5.1 全局统计卡片

- **① 功能**：展示当前系统内**所有已开启赛程**的实时汇总数据，不受底部筛选区的「比赛日」时间范围影响。共 7 张卡片：总赛事、🔴 滚球、⏰ 即将、📅 赛前、⏸ 延期、🎯 待上架、✓ 上架中。
- **② 逻辑定义**：数据范围为全系统所有启用中的联赛赛事，独立于页面当前筛选条件。卡片数字为只读展示，**点击不触发任何筛选**。待上架与上架中从上架状态维度统计。
- **③ 操作后体现**：卡片数字随系统赛事状态实时变化。
- **④ 备注 / 权限**：所有角色可见。

### 5.2 刷新

- **① 功能**：手动刷新当前列表数据至最新状态。
- **② 逻辑定义**：触发后重新拉取符合当前所有筛选条件的赛事数据。
- **③ 操作后体现**：Toast 提示「刷新成功」，列表更新。
- **④ 备注 / 权限**：所有角色可见。

### 5.3 更多配置下拉

- **① 功能**：折叠次要全局配置入口，包含「⚠️ 告警配置」和「👥 人员配置」两项。
- **② 逻辑定义**：点击「⚙️ 更多配置 ▾」展开下拉菜单，点击菜单外区域收起。「告警配置」所有角色可见；「人员配置」仅主管/风控可见。
- **③ 操作后体现**：点击「告警配置」→ 弹出告警配置弹窗（详见§十一）；点击「人员配置」→ 展开人员配置浮窗（详见§十二）。
- **④ 备注 / 权限**：入口本身所有角色可见，「人员配置」子项仅主管/风控显示。

### 5.4 一键锁盘

- **① 功能**：批量锁定异常赛事的所有盘口，停止接受新投注。
- **② 逻辑定义**：点击后弹出「异常赛事清单」弹窗（详见§九），由主管从系统识别的异常赛事列表中勾选要锁定的赛事，二次确认后执行。锁定后数据源状态变更不会自动解锁，必须由主管/风控手动执行解锁。
- **③ 操作后体现**：被锁定赛事的盘口状态变为「🔒 锁定」；Toast 提示已锁定 N 场。
- **④ 备注 / 权限**：**仅主管 / 风控可见且可操作**。

### 5.5 一键解锁

- **① 功能**：批量解锁已锁定赛事，恢复盘口接受投注。
- **② 逻辑定义**：点击后弹出「已锁定赛事清单」弹窗（详见§十），由主管从列表中勾选要解锁的赛事，填写必填解锁原因后二次确认执行。
- **③ 操作后体现**：被解锁赛事盘口状态恢复；Toast 提示已解锁 N 场。
- **④ 备注 / 权限**：**仅主管 / 风控可见且可操作**。

## 六、筛选区

### 6.1 第 1 行：比赛日选择

- **① 功能**：按比赛日期范围筛选列表赛事。提供快捷按钮（昨日 / 今日 / 明日 / 后天）和自定义日期时间区间（精确到秒）。
- **② 逻辑定义**：快捷按钮互斥，点击后自动填充对应日期的 00:00:00 ~ 23:59:59 到自定义输入框；自定义区间点「应用」后生效，此时快捷按钮变为非激活态。默认选中「今日」。此行选择的时间范围**影响下方第 2 行可见范围 Tab 的统计数字**，以及主列表赛事的查询范围。
- **③ 操作后体现**：列表按选定日期范围重新加载；自定义应用后显示蓝色提示「已应用自定义日期时间」。
- **④ 备注 / 权限**：所有角色可见。

### 6.2 第 1 行右侧：快捷场景按钮

包含两个 Toggle 按钮，仅主管/风控可见：

**「⚠️ 待分配赛事」**
- **① 功能**：一键筛选所有尚未分配操盘手的赛事，并将分配操盘手与上架合并为单次流程。
- **② 逻辑定义**：激活后主列表只显示「赛前/滚球任意阶段操盘手为未分配」的赛事，不受其他筛选条件限制。通过此入口进入分配操盘手弹窗完成分配后，系统自动触发上架流程（分配 + 上架合并，缩短操作路径）。批量操作栏的「分配操盘手」按钮同样支持此合并流程。
- **③ 操作后体现**：按钮高亮，列表收敛为未分配赛事；完成分配操作后 Toast 提示「分配 + 上架成功，已将 N 场赛事分配给指定操盘手，系统自动上架」。
- **④ 备注 / 权限**：**仅主管 / 风控可见**。

**「👤 我负责的」**
- **① 功能**：筛选当前登录用户作为操盘手（赛前或滚球阶段）负责的赛事。
- **② 逻辑定义**：激活后主列表只显示当前用户被分配的赛事（赛前或滚球阶段有其名字即纳入）。
- **③ 操作后体现**：按钮高亮，列表收敛为本人负责赛事。
- **④ 备注 / 权限**：**仅主管 / 风控可见**（主管也可能亲自负责具体赛事；普通操盘员默认只能看到自己负责的赛事，该按钮对其冗余故隐藏）。

### 6.3 第 2 行：可见范围 Tab

- **① 功能**：按比赛进程阶段快速切换列表视图。Tab 共 4 项：📋 全部 / 🔴 滚球 / ⏰ 即将 / 📅 赛前。
- **② 逻辑定义**：Tab 旁的数字统计**受第 1 行比赛日时间范围影响**，随日期切换而变化；与顶部全局统计卡片数字相互独立。滚球和即将 Tab 旁标注「实时」标签，表示数据实时推送。
- **③ 操作后体现**：点击 Tab → 列表按对应进程过滤；当前激活 Tab 高亮。
- **④ 备注 / 权限**：所有角色可见。

### 6.4 第 3 行：赛事状态 + 上架状态

**赛事状态**（单选组，默认「全部」）：全部 / 正常 / ⏸ 延期

**上架状态**（单选组，默认「全部」）：全部 / 待上架 / 已上架 / 已下架

- **① 功能**：按赛事状态和上架状态进行双维度筛选。
- **② 逻辑定义**：两组各自独立单选，互不影响。「全部」为默认选中态（蓝色激活）；选中非「全部」项时对应状态蓝色激活，「全部」取消激活。延期旁有红色数字角标显示当前延期场数。待上架旁有数字角标显示待上架场数。
- **③ 操作后体现**：列表按所选状态组合过滤，两组条件同时生效（AND 关系）。
- **④ 备注 / 权限**：所有角色可见。

### 6.5 第 4 行：其他筛选

提供以下筛选控件，从左到右依次排列：

| 控件 | 选项说明 | 权限 |
|------|----------|------|
| 全部联赛（下拉） | 仅显示当前可见配置内的联赛，后端 API 过滤 | 全部 |
| 联赛等级（下拉） | 等级 1 ~ 10，仅显示配置内的等级 | 全部 |
| 告警状态（下拉） | 全部 / 有告警 / 无告警 / 单边超限 / 大额投注 | 全部 |
| 全部操盘手（下拉） | 显示系统内所有操盘员，筛选指定操盘手负责的赛事 | 仅主管/风控 |
| 搜索框 | 搜索赛事/球队/ID，输入停止 800ms 后触发，Enter 立即触发 | 全部 |
| 排序（下拉） | 默认排序 / 按开赛时间 / 按投注额 / 按单边比例 / 按盈亏 | 全部 |

- **④ 备注 / 权限**：「全部操盘手」下拉仅主管/风控显示；其余控件所有角色可见。

### 7.2 行样式规则

行的背景色与左侧色条反映赛事的紧急程度与阶段：

| 行样式 | 触发条件 | 视觉表现 |
|--------|----------|----------|
| 最紧急（row-critical） | 待上架 + 已滚球 | 红色背景脉冲动画 + 左侧红色色条 |
| 紧急（row-urgent） | 待上架 + 即将开赛（≤10分钟） | 浅红色背景 + 左侧蓝色色条 |
| 告警（row-danger / row-alert） | 已上架 + 存在高风险告警 | 浅红/浅橙背景 |
| 延期（row-delay） | 赛事状态=延期 | 浅橙背景，开赛时间加删除线 |
| 中场休息（row-halftime） | 比赛进程=中场休息 | 浅橙背景 + 左侧橙色色条 |
| 滚球（row-live） | 比赛进行中 | 左侧红色色条 |
| 赛前（row-prematch） | 比赛未开始 | 左侧蓝色色条 |
| 已下架（row-normal，降透明度） | 上架状态=已下架 | 整行 opacity: 0.6 |
| 正常（row-normal） | 无以上条件 | 无特殊背景 |

### 7.3 操作按钮动态规则

操作列按钮根据赛事的上架状态和当前阶段动态显示：

| 上架状态 | 可用按钮 | 说明 |
|----------|----------|------|
| 待上架 | **上架**、详情 | 点「上架」→ 上架确认弹窗 |
| 已上架 | **下架**、**操盘**、详情 | 点「下架」→ 下架确认弹窗；点「操盘」→ 跳转操盘详情页 |
| 已下架 | **🔄 重新上架**、详情 | 重新上架流程与普通上架相同；该按钮仅在赛事经历「上架→下架」后出现 |

> 「详情」按钮对应操盘日志弹窗（详见§八.4）。

### 7.4 表格分组

普通区域的赛事按联赛分组显示，每个联赛有分组标题行，显示国旗、联赛名、赛事场数及收起/展开控制。

### 7.5 分页器

- 显示「共 N 场赛事」总数；每页条数可选（20 / 50 / 100）；支持上一页/下一页、首页/末页、页码跳转。

## 八、操作弹窗

### 8.1 上架确认弹窗

- **① 功能**：确认单场赛事的上架操作，可选择上架后是否对 C 端隐藏。
- **② 逻辑定义**：
  - 弹窗展示所选赛事数量、其中已滚球场数（标红）、即将开赛（≤10分钟）场数（标橙）。
  - 提供「隐藏」勾选项：勾选 = 上架后赛事对玩家不可见（适用于高风险或需复核的赛事），不勾 = 玩家立即可投注。默认不勾。
  - 系统不因「紧急赛事 + 勾选隐藏」的组合弹出额外警告，信任主管判断。
  - 弹窗底部有提示：上架前请确保已分配操盘手。
- **③ 操作后体现**：点「确认上架」→ 赛事上架状态变为「已上架」（或「已上架 + 隐藏」）；Toast 提示「上架成功，N 场赛事已成功上架」。
- **④ 备注 / 权限**：所有可执行上架操作的角色（主管/风控/操盘员均可触发，但不同角色显示范围可能不同）。

### 8.2 批量上架弹窗（逐场设置）

- **① 功能**：批量勾选多场赛事后，统一设置操盘手分配（按阶段）并逐场控制是否隐藏。
- **② 逻辑定义**：
  - 顶部展示本次选中赛事概况（总场数、已滚球数、即将开赛数、赛前数）。
  - **操盘员分配（按阶段）**：分「赛前」和「滚球」两个下拉分别选择操盘员，统一应用到本次所有选中赛事（每场上架后可单独调整）。
  - **逐场隐藏控制**：列表展示每场赛事，每场有独立「隐藏」勾选项。紧急赛事（已滚球/即将开赛）红色背景显示，其余正常背景。
  - 辅助操作：「全选隐藏」「取消全选」「按状态智能勾」（智能勾 = 勾所有赛前赛事、取消所有紧急赛事）。
  - 系统不对「紧急赛事 + 勾选隐藏」组合弹出警告。
- **③ 操作后体现**：点「确认上架」→ Toast 提示「批量上架成功，N 场赛事已上架，其中 M 场已隐藏对玩家不可见」。
- **④ 备注 / 权限**：由批量操作栏触发；仅主管/风控可执行批量上架。

### 8.3 分配操盘手弹窗

- **① 功能**：为选中的赛事分别指定赛前阶段和滚球阶段的操盘员。
- **② 逻辑定义**：
  - 展示已选赛事数量及当前操盘手情况。
  - 提供「赛前阶段」和「滚球阶段」两个独立下拉选择框，可分配给同一人或不同人；留空表示该阶段不分配。
  - 入口有两处：①操盘手列点击「未分配」标签；②批量操作栏「分配操盘手」按钮。
  - 从「⚠️ 待分配赛事」入口进入时，完成分配后自动触发上架流程（分配 + 上架合并）；从其他入口进入时，仅执行分配，不自动上架。
- **③ 操作后体现**：普通入口 → Toast 提示「分配成功，已将 N 场赛事分配给指定操盘手」；待分配入口 → Toast 提示「分配 + 上架成功」。操盘手列即时更新。
- **④ 备注 / 权限**：**仅主管 / 风控可操作**（普通操盘员触发时提示无权限）。

### 8.4 操盘日志弹窗

- **① 功能**：查看指定赛事的全部操盘操作记录。
- **② 逻辑定义**：
  - 筛选条件：时间范围（最近 1 小时 / 今天 / 最近 3 天 / 自定义）、操作类型（状态变更 / 赔率调整 / 盘口线调整 / 返奖率调整 / 数据源开关变更 / 飞单开关变更 / 操盘手变更）、操作来源（人工 / 数据源 / 风控 / 系统 / 上级联动）、盘口 ID。
  - 日志列表字段：时间（精确到秒）、操作类型（彩色标签）、盘口、操作详情（变更前后值）、操作人、来源（彩色标签）。
  - 支持导出日志；支持分页（每页展示，显示共 N 条/第 X 页）。
- **③ 操作后体现**：点「🔍 查询」按钮刷新列表；点「📥 导出」下载日志文件。
- **④ 备注 / 权限**：所有角色可查看（点「详情」按钮触发）。

### 8.5 下架确认弹窗

- **① 功能**：确认将已上架赛事下架，停止接受新投注。
- **② 逻辑定义**：
  - 展示选中赛事数量、当前投注额（多币种分行显示）、未结算注单数（多币种分行显示）。
  - 警告说明：下架后所有盘口变为隐藏状态（C 端不可见），停止接受新投注；已有注单不受影响，比赛结束后正常结算。
- **③ 操作后体现**：点「确认下架」→ 赛事上架状态变为「已下架」，盘口全部隐藏；Toast 提示「下架成功，赛事已下架，盘口已隐藏」。
- **④ 备注 / 权限**：所有角色可触发（操作按钮或批量操作栏）。

## 九、一键锁盘弹窗

- **① 功能**：从系统识别的异常赛事清单中勾选要锁定的赛事，锁定后所有盘口停止接受新投注。
- **② 逻辑定义**：
  - 弹窗顶部说明系统识别的异常赛事数量。
  - 列表每行显示：赛事ID + 主客队名、异常标签（货量大 / 单边超限 / 数据源延迟 / IM 异常 / 偏差大等，色标区分严重程度）、赛事进程与联赛。
  - 支持「全选」复选框，支持点击行选中/取消。
  - 底部显示「自动刷新中（每 5 秒）」指示器和当前已选 N / 总数计数。
  - 点「🔒 锁定选中」→ 弹出二次确认弹窗：展示锁定后的影响说明（所有盘口停止接受投注 / 数据源恢复不自动解锁 / 需主管手动解锁）+ 锁定原因输入框（选填）。
- **③ 操作后体现**：确认后 Toast 提示「已锁定 N 场赛事」；被锁定赛事盘口状态变为「🔒 锁定」。
- **④ 备注 / 权限**：**仅主管 / 风控可见且可操作**。

## 十、一键解锁弹窗

- **① 功能**：从已锁定赛事清单中勾选要解锁的赛事，恢复盘口接受投注。
- **② 逻辑定义**：
  - 弹窗顶部显示当前处于锁定状态的赛事总数。
  - 列表每行显示：赛事ID + 主客队名、锁定时间 + 操作人 + 锁定原因、赛事进程与联赛。
  - 支持「全选」，支持点击行选中/取消；底部显示「自动刷新中（每 5 秒）」及已选计数。
  - 点「🔓 解锁选中」→ 弹出二次确认弹窗：展示解锁后影响说明（盘口恢复接受投注 / 解锁前请确认风险已消除）+ 解锁原因输入框（**必填**，用于审计追责；未填写点确认时 Toast 提示「请填写解锁原因」）。
- **③ 操作后体现**：确认后 Toast 提示「已解锁 N 场赛事」；被解锁赛事盘口状态恢复正常。
- **④ 备注 / 权限**：**仅主管 / 风控可见且可操作**。

## 十一、批量操作浮动栏

- **① 功能**：选中一条或多条赛事后，从页面底部居中滑入浮动操作栏，提供批量操作入口。
- **② 逻辑定义**：
  - 显示「已选择 N 场赛事」计数（N 随勾选实时变化）。
  - 按钮列表：**批量上架**（→ 批量上架弹窗）、**🔄 批量重新上架**（针对已下架赛事，流程与批量上架相同）、**批量下架**（→ 下架确认弹窗）、**分配操盘手**（仅主管/风控，→ 分配操盘手弹窗）、**取消选择**（清空所有勾选，收起浮动栏）。
  - 表头全选复选框可一次性选中/取消当前页全部赛事。
  - 浮动栏右侧有「×」按钮，功能等同「取消选择」。
- **③ 操作后体现**：取消选择或操作完成后浮动栏收起；各按钮点击后跳转对应弹窗。
- **④ 备注 / 权限**：「分配操盘手」按钮仅主管/风控显示；其余按钮所有角色可见。

## 十二、告警通知系统

告警通知分三层展示，按严重程度分级处理：

| 层级 | 位置 | 类型 | 行为 |
|------|------|------|------|
| 严重告警（Critical） | 右上角驻留 | 最紧急 / 紧急 | 驻留不自动消失，支持手动关闭；多条时叠加角标显示 +N |
| 警告告警（Warning） | 右下角堆叠 | 大额 / 延期超时 / 比赛暂停等 | 自动消失（持续时长由严重程度决定），最多同时显示 3 条 |
| 提示告警（Info） | 右下角堆叠 | 数据延迟 / 中立场等 | 同上，自动消失 |

**告警类型与色标**（以原型为准）：

| 告警类型 | 级别 | 色标 |
|----------|------|------|
| 滚球未上架（待上架 + 已开球） | 严重 🔴 | 红 |
| 即将开赛未上架（待上架 + ≤10分钟） | 严重 🔴 | 红 |
| 单边超限 | 严重 🔴 | 红 |
| 延期超时 | 警告 🟠 | 橙 |
| 大额投注 | 警告 🟠 | 橙 |
| 比赛暂停 | 警告 🟠 | 橙 |
| 数据源暂停 | 警告 🟠 | 橙 |
| 未分配操盘手 | 警告 🟠 | 橙 |
| 维护中 | 提示 🟣 | 紫 |
| 数据延迟 | 提示 🔵 | 蓝 |
| 中立场提醒 | 提示 🔵 | 蓝 |
| 进球提醒（足球滚球事件） | 提示 ⚽ | 绿 |
| 红牌提醒（足球滚球事件） | 提示 🟥 | 红 |

列表行内「告警」列以轮播方式展示当前赛事的全部告警标签：单条直接显示，多条每 3 秒切换一条，右上角显示「当前条/总数」计数。新增告警时对应行闪烁提示。

## 十三、告警配置弹窗

- **④ 备注 / 权限**：由「更多配置 ▾」→「告警配置」触发；所有角色可配置。

## 十四、消息中心

- **① 功能**：以抽屉形式从右侧滑出，集中展示历史告警消息，区分已读/未读。
- **② 逻辑定义**：顶部导航栏有「🔔」触发按钮，旁边红色角标显示未读消息数；点击触发打开消息中心抽屉，主内容区向左推让出 380px。消息按时间倒序排列，分「最紧急/严重（左红色）」「警告（左蓝色）」类型用左侧色条区分；点击消息条目标记为已读；未读消息旁有「● 未读」红色标记。
- **③ 操作后体现**：打开消息中心后内容区右移，点「✕」关闭后内容区复位；点击消息条目后「未读」标记消失。
- **④ 备注 / 权限**：所有角色可见。

## 十五、人员配置浮窗

- **① 功能**：主管专属的可拖动浮窗，实时显示当前所有操盘员的在线状态和负责赛事数量，便于主管统筹调度。
- **② 逻辑定义**：
  - 浮窗默认显示在页面左下角，可自由拖拽到任意位置。
  - 显示每位操盘员的姓名、在线/离线状态（绿/灰点）、当前赛前负责场数、当前滚球负责场数。
  - 离线人员赛前/滚球数字显示为 0（不计入在岗工作量）。
  - 顶部统计行显示：N 名值班（X 在线 / Y 离线）· 共 Z 场（Z 取自主列表「共 N 场赛事」总数，非各人数字累加）。
  - 支持「仅看在线」Toggle 过滤离线人员；支持「排序」切换（按负责场数降序 / 按姓名）；支持「⟳ 刷新」；支持「─ 最小化」（折叠正文只留标题栏）；支持「✕ 关闭」（关闭后需从「更多配置 ▾」→「人员配置」重新打开）。
- **③ 操作后体现**：浮窗数据随操盘手分配变更实时更新；排序/过滤操作即时刷新列表。
- **④ 备注 / 权限**：**仅主管 / 风控可见**；普通操盘员视角下完全不显示。
