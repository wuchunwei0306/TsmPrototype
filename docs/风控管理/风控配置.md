## 一、模块概述

风控配置用于设置各类限额和告警阈值，是风控管理的核心配置入口。

- 使用者为**操盘主管**和**运营人员**，两者均可查看和编辑所有配置项。
- 所有金额类配置均支持 **CNY / USDT / VND** 三种币种独立配置，CNY 为基准。
- 侧边栏提供全局汇率工具，有效期 1 分钟，可一键换算填入 USDT / VND。
- 每个功能按四点写：**① 功能　② 逻辑定义　③ 操作后体现　④ 备注 / 权限**。

## 二、名词定义

| 术语 | 含义 |
|------|------|
| 联赛等级 | 等级 1（最高级）~ 等级 10（最低级）+ 未分配，共 11 档；在联赛管理中分配 |
| 单场最大货量 | 整场赛事可接受的最大总投注额 |
| 分组货量 | 六个玩法分组（让球/大小/角球/进球/半场/特殊）各自的最大货量上限 |
| 单用户货量 | 单个用户在该玩法分组内的最大累计投注额 |
| 单注下限 / 上限 | 单笔注单允许的最小 / 最大金额 |
| 全局累计货量 | 跨赛事合计的玩法累计投注额（玩法限额使用此概念）|
| 风控告警 | 达到阈值时在操盘列表 / 操盘详情页触发的标记，供操盘手处理 |

## 四、全局汇率工具

- **① 功能**：显示当前 CNY/USDT 和 CNY/VND 汇率，供各配置面板的「按汇率换算填入」功能使用。
- **② 逻辑定义**：汇率需手动点击「刷新」更新；有效期为 1 分钟，超过 1 分钟后显示「⚠ 汇率不是最新，请刷新」黄色提示。汇率更新时间精确到秒显示。
- **③ 操作后体现**：刷新后显示最新汇率和更新时间；各面板点击「按汇率换算填入 USDT / VND」时使用此汇率计算并写入对应输入框。
- **④ 备注 / 权限**：侧边栏常驻展示；操盘主管和运营人员均可使用。

## 五、联赛限额配置

- **① 功能**：按联赛等级（11 档）× 玩法分组（7 个 Tab）的矩阵结构，配置各等级各分组的货量和单注限额。
- **② 逻辑定义**：

  **Tab 切换**（页面顶部）：整体限额 / 让球 / 大小 / 角球 / 进球 / 半场 / 特殊，共 7 个 Tab，切换后矩阵列结构变化。

  **矩阵行**：未分配、等级1 ~ 等级10，共 11 行；等级 1 为最高级，各行独立配置。

  **矩阵列结构**：

  | Tab | 列名 | 说明 |
  |-----|------|------|
  | 整体限额 | 单场最大货量 | 整场赛事总投注额上限，按 CNY/USDT/VND 三列展示 |
  | 各玩法 Tab（让球/大小等） | 分组货量 | 该分组内可接受的最大总投注额 |
  | | 单用户货量 | 单个用户在该分组内的累计投注上限 |
  | | 单注下限 | 单笔注单最小金额 |
  | | 单注上限 | 单笔注单最大金额 |

  每个数值列均有 CNY / USDT / VND 三个子列；整体限额 Tab 中每行有独立**启用开关**，控制该等级的整体货量校验是否生效。顶部提供「按汇率换算填入 USDT / VND」一键换算。

- **③ 操作后体现**：点击「保存」→ Toast 提示「保存成功」；点击「恢复默认」→ 还原系统默认值。配置保存后，对应等级联赛的新上架赛事按新限额执行，已上架赛事不受影响。
- **④ 备注 / 权限**：操盘主管和运营人员均可编辑。此处配置的「分组货量、单用户货量、单注限额」会在联赛管理串关配置里以只读方式展示。

## 六、用户限额配置

- **① 功能**：配置单个用户的全局投注行为限制，不区分联赛等级，全局统一生效。
- **② 逻辑定义**：配置项共 4 类，每类均有 CNY / USDT / VND 三个子列：

  | 配置项 | 说明 |
  |--------|------|
  | 单用户单比赛最大货量 | 单个用户在同一场赛事内的累计投注上限 |
  | 单用户单玩法最大货量 | 单个用户在同一场赛事同一玩法的累计投注上限 |
  | 单注投注区间（下限～上限） | 单笔注单的金额范围（含普通注单） |
  | 串关投注区间（下限～上限） | 串关注单的单注金额范围 |

  提供「按汇率换算填入 USDT / VND」一键换算功能。

- **③ 操作后体现**：点击「保存」→ Toast 提示「保存成功」；全局立即生效。
- **④ 备注 / 权限**：操盘主管和运营人员均可编辑。

---

## 七、玩法限额配置

- **① 功能**：按 6 个分组管理 208 种足球玩法的**全局累计货量上限**（跨所有赛事合计）。
- **② 逻辑定义**：

  **Tab 切换**：让球 / 大小 / 角球 / 进球 / 半场 / 特殊，共 6 个分组 Tab。

  每个 Tab 内为该分组所有玩法的列表，列结构：玩法ID（BT 编号）、玩法名称、CNY 上限、USDT 上限、VND 上限。可滚动，最大高度固定（约展示 15 行）。

  各玩法的上限含义为：该玩法在**全部赛事**中累计接受的最大总投注额；超出后该玩法停止接受新投注直到结算释放。

- **③ 操作后体现**：点击「保存」→ 保存当前 Tab 玩法的配置；全局立即生效。
- **④ 备注 / 权限**：操盘主管和运营人员均可编辑。此处为跨赛事**全局**累计限额，与联赛限额（单场分组货量）独立生效，两者均满足才能接受投注。

## 八、串关限额配置

- **① 功能**：配置各类串关的单注限额和总货量上限，全局配置，不区分联赛等级。
- **② 逻辑定义**：

  按串关类型逐行配置，每行含两组数值（各有 CNY / USDT / VND 三列）：

  | 列名 | 说明 |
  |------|------|
  | 单注限额 | 单笔串关注单的最大金额 |
  | 总货量上限 | 该类型串关的全局总投注上限 |

  串关类型包含一般串关（2串1 ~ 10串1）以及复式串关（3串4、3串7、4串11、4串15、5串26、5串31、6串57、6串63 等）。各类型的**启用 / 停用**控制在联赛管理中配置，此处只管限额数值。

- **③ 操作后体现**：点击「保存」→ Toast 提示「保存成功」；全局立即生效。
- **④ 备注 / 权限**：操盘主管和运营人员均可编辑。联赛管理串关配置中的限额字段为只读，数值来源即本面板。

## 九、告警阈值配置

- **① 功能**：配置各类告警的触发条件、阈值和启用状态；告警触发后在操盘列表和操盘详情页显示告警标记。
- **② 逻辑定义**：分两类：

  **比例类告警**（全局统一，不受币种影响）：

  | 告警类型 | 触发条件 | 默认阈值 |
  |----------|----------|---------|
  | 偏离数据源告警 | 本地赔率与 IM 赔率偏离值绝对值超过阈值 | 0.10 |
  | 单边投注告警 | 某选项投注占比超过阈值 | 70% |
  | 货量接近上限告警 | 货量占限额比例达到阈值（整场维度 + 各分组维度双重检测）| 80% |

  **金额类告警**（按币种独立配置，CNY / USDT / VND 各自设置阈值）：

  | 告警类型 | 触发条件 |
  |----------|----------|
  | 风险敞口告警 | 赛事风险敞口金额超过阈值 |
  | 大额投注告警 | 单笔注单金额超过阈值 |

  所有告警均有启用/停用开关；金额类同样提供「按汇率换算填入 USDT / VND」。

- **③ 操作后体现**：点击「保存」→ Toast 提示「保存成功」；配置立即生效，新触发的告警按新阈值判断。
- **④ 备注 / 权限**：操盘主管和运营人员均可编辑。

## 十、字段说明（各配置面板公共规则）

| 字段规则 | 说明 |
|----------|------|
| CNY 为基准货币 | 所有金额类配置以 CNY 输入为主，USDT / VND 可手动填写或按汇率换算填入 |
| 汇率换算填入 | 点击面板顶部「按汇率换算填入 USDT / VND」，以侧边栏当前汇率将 CNY 值换算后写入；汇率超过 1 分钟需先刷新 |
| 输入格式 | 金额类：正整数，不含小数点；比例类：百分比数值（如输入 70 表示 70%）；偏离值：支持两位小数 |
| 保存 | 每个面板独立保存，保存后立即生效 |
| 恢复默认 | 仅还原当前面板数据，不影响其他面板 |

## 十二、与其他模块的关系

| 本模块配置 | 关联模块 | 关系说明 |
|-----------|---------|---------|

## 十三、验收要点

| 编号 | 验证内容 | 预期结果 |
|------|----------|----------|
| 1 | 汇率超过 1 分钟未刷新，点击「按汇率换算填入」 | 显示「汇率不是最新，请先刷新」提示，不执行换算 |
| 2 | 联赛限额矩阵切换至「让球」Tab | 矩阵列变更为分组货量 / 单用户货量 / 单注下限 / 单注上限，各含 CNY/USDT/VND 三子列；行保持 11 行不变 |
| 3 | 整体限额 Tab 关闭某等级启用开关并保存 | 该等级赛事不再校验整体货量上限；其他等级不受影响 |
| 4 | 修改联赛限额并保存 | 已上架赛事限额不变；之后新上架赛事按新限额校验 |
| 5 | 修改用户限额并保存 | 全局立即生效，之后所有新注单按新限额校验 |
| 6 | 玩法限额切换分组 Tab | 该分组所有玩法（BT 编号 + 名称）列表正确展示，可滚动 |
| 7 | 告警阈值关闭「单边投注告警」开关并保存 | 操盘列表不再触发单边超限告警标记 |
| 8 | 货量接近上限告警触发提示内容 | 提示示例「让球组货量接近上限：250,000 / 300,000（83.3%）」，包含分组名、当前值、上限值、百分比 |
