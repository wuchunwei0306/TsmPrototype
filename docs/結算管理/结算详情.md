## 一、模块概述

结算详情是结算管理的**核心作业页面**，以单场赛事为单位，供结算人员逐盘口执行结算操作。

进入方式：从结算列表点击「结算」或「详情」按钮跳转。

- 页面由**赛事信息头**、**提示栏**、**盘口数据汇总**、**盘口列表**四部分组成。
- 结算分为自动与人工两种路径（L1～L4 分层，详见结算列表 §5.6 说明）；需人工处理的盘口优先展示。
- 腰斩处置依赖 IM 数据源推送，无 IM 推送时操作显示失败。
- 每个功能按四点写：**① 功能　② 逻辑定义　③ 操作后体现　④ 备注 / 权限**。

## 二、名词定义

| 术语 | 含义 |
|------|------|
| 可操盘盘口 | 让球、大小等支持本地结算操作的盘口 |
| 数据源盘口 | 角球、波胆等由 IM 直接推送结算结果的盘口（L1）|
| 基准分 | 结算时使用的比分快照；赛前投注以终场比分为基准，滚球投注以投注瞬间之后的最终比分为基准 |
| 多组基准分 | 含多条盘口线的玩法，每条线可能对应不同基准分组 |
| 驳回 | 将已结算赛事回退为待结算；距最新结算时间 ≤ 24h（UTC）方可操作 |
| 腰斩 | 比赛中途终止；已完成时段按比分结算，未完成时段退款 |
| 二次结算 | 对已结算盘口重新执行结算；驳回窗口内方可操作 |
| 关盘 | 盘口绝对终态，无人工回退入口；关盘后进入可结算状态 |
| VAR 观察窗口 | 分段结算前等待 VAR 介入的等待期（5 分钟）|

## 三、赛事信息头

- **① 功能**：展示当前赛事的基本信息、结算进度，并提供赛事级操作按钮。
- **② 逻辑定义**：

  **展示内容（上半部分）**：联赛旗帜 + 名称、主客队名、终场比分 + 半场比分（蓝色大字）、整体结算状态标签（待结算/已结算）、已处理盘口数/总盘口数（如「2 / 8 盘口待处理」）。

  **展示内容（下半部分）**：赛事ID、开赛时间、完赛时间、结算人员（点击触发分配弹窗，详见 §八）。

  **赛事级操作按钮三按钮互斥显示规则**：

  | 按钮 | 显示条件 | 功能 |
  |------|---------|------|
  | ⚠️ 赛事异常处理 | 赛事 = 待结算 | 结算人员主动发起异常处置（详见 §六）|
  | ↶ 赛事驳回 | 赛事 = 已结算/已取消/异常，且距最新结算时间 ≤ 24h（UTC） | 回退赛事为待结算（详见 §七）|
  | ✓ 结算赛事 | 赛事 = 待结算 + 所有盘口已结算或已取消 | 最终确认并执行派彩（详见 §五）|

- **③ 操作后体现**：结算赛事后状态变为「已结算」；驳回后状态回退为「待结算」。
- **④ 备注 / 权限**：结算主管和结算员均可操作所有按钮。

---

## 四、提示栏（Notice Bar）

赛事信息头下方的动态提示条，根据赛事当前状态显示对应提示，可手动关闭（✕）：

| 触发场景 | 提示内容 |
|---------|---------|
| VAR 观察窗口 | 显示倒计时（5 分钟），提醒结算人员分段结算前等待 VAR 介入；窗口期内建议不执行结算，但系统不强制阻止 |
| 自动重结算聚合窗口 | 窗口期（5 分钟）内 IM 多次推送比分变化，系统仅按窗口期最后一次比分执行一次差额处理；显示推送次数和比分轨迹；结算人员主动点「二次结算」将立即终止窗口，丢弃中间态比分 |
| 腰斩暂缓 | 提示腰斩处置方式，引导结算人员前往「⚠️ 赛事异常处理」操作 |

## 五、结算赛事确认弹窗（前置校验）

- **① 功能**：最终确认结算赛事前展示前置校验清单，防止漏结算。
- **② 逻辑定义**：触发条件：赛事 = 待结算 + 所有盘口已结算或已取消（✓ 结算赛事按钮可点）。弹窗展示：赛事基本信息、所有盘口结算状态汇总、串关关联情况（有关联串关时提示「N 笔串关可结算」）、总投注额与预计派彩。确认后执行派彩并锁定赛事结算状态。
- **③ 操作后体现**：赛事状态变为「已结算」，结算时间写入；派彩执行；结算列表卡片状态同步更新。
- **④ 备注 / 权限**：结算主管和结算员均可操作。

---

## 六、赛事异常处理弹窗

- **① 功能**：结算人员主动发起赛事异常处置，支持 4 种类型。
- **② 逻辑定义**：

  **4 种处置类型**：

  | 处置类型 | 含义 | 处理方式 |
  |---------|------|---------|
  | 取消赛事 | 整场赛事取消 | 所有注单全额退款 |
  | 延期 | 比赛推迟，注单保留 | 赛事标记为延期，注单挂起等待 |
  | 腰斩 | 比赛中途终止（依赖 IM 推送） | 已完成时段按当前比分结算，未完成时段退款；弹窗内选择各时段处置方式 |
  | 数据错误 | 赛果录入有误 | 纠正赛果后重新触发结算 |

  **取消范围选择**（取消赛事/盘口时）：全部注单 / 指定盘口 / 指定盘口线，对应不同退款范围。

  **腰斩处置逻辑**：腰斩事件由 IM 三方推送触发，**无 IM 推送时人工操作将显示失败**，赛事状态不变。弹窗内展示腰斩发生时刻（如「腰斩暂缓 78'」）和已完成/未完成时段明细，结算人员选择每个时段的处置方式后确认执行。

  **取消原因**（必填，用于审计记录）。

- **③ 操作后体现**：赛事状态更新为对应异常类型；操作日志记录「操作人 + 原因 + 时间」；相关注单按处置结果执行退款或结算；腰斩失败时 Toast 提示「操作失败：未收到 IM 数据推送」。
- **④ 备注 / 权限**：结算主管和结算员均可操作。

---

## 七、赛事驳回弹窗

- **① 功能**：将已结算赛事回退为待结算状态，供重新执行结算。
- **② 逻辑定义**：
  - **驳回窗口**：距赛事最新结算时间 ≤ 24h（UTC）方可操作；每次重新确认结算后窗口向后滚动（重新计 24h）；超出窗口后「赛事驳回」按钮不再显示。
  - **驳回范围**：仅将赛事状态回退为待结算，不自动影响盘口/注单/母单的当前状态；盘口需在详情页重新逐一操作。
  - **驳回原因**（必填，用于审计）。
- **③ 操作后体现**：赛事状态变为「待结算」；结算列表该赛事日志显示「操作人 执行赛事驳回（已结算→待结算），原因：XXX」及驳回窗口剩余倒计时。
- **④ 备注 / 权限**：结算主管和结算员均可操作。

---

## 八、结算人员分配弹窗

- **① 功能**：为当前赛事指定结算人员。
- **② 逻辑定义**：点击赛事信息头「结算人员」字段（显示为可点击样式 + 铅笔图标）触发；弹窗内选择结算人员（单一人员，不分阶段）。
- **③ 操作后体现**：确认后赛事信息头「结算人员」字段即时更新；Toast 提示分配成功。
- **④ 备注 / 权限**：结算主管和结算员均可操作。

---

## 九、盘口数据汇总

- **① 功能**：按可操盘盘口 / 数据源盘口 / 合计三组展示本场资金汇总。
- **② 逻辑定义**：三组各显示盘口数、注单数、总投注额、预计派彩、平台盈亏（正值绿色，负值红色）。
- **③ 操作后体现**：随盘口结算进度实时刷新。
- **④ 备注 / 权限**：只读展示，所有角色可见。

## 十、盘口列表

### 10.1 盘口 Tab

- **可操盘盘口**（默认）：让球、大小等可本地操作的盘口，含 L2/L3/L4 层级。
- **数据源盘口**：角球、波胆等 L1 层级盘口，由 IM 直接推送结算结果，此 Tab 以只读方式展示结算状态。

### 10.2 工具栏

| 控件 | 功能 |
|------|------|
| 赛事阶段筛选 | 全部 / 滚球 / 赛前，按投注时的比赛阶段过滤 |
| 赛制时段 Tab | 全部 / 上半场(1H) / 下半场(2H) / 15分钟段 / 全场(FT) / 事件触发 |
| 盘口状态筛选（下拉） | 全部 / 开盘中（可投注）/ 关盘（待结算/已关盘）/ 已结算 / 已取消 |
| 搜索框 | 按 BT 编号或玩法名搜索 |
| 赛果录入按钮组 | 4 个分时段按钮（详见 §10.3）|
| 全部展开 / 全部收起 | 控制所有盘口卡片的展开/收起状态 |

**盘口分组锚点导航**（工具栏下方）：按判定时机分 5 类，点击跳转对应分组：上半场类(1H) · 15分钟段类 · 事件触发类 · 全场类(FT) · 比分变动触发类。

### 10.3 赛果录入（4个分时段按钮）

| 按钮 | 颜色 | 影响时段 | 影响盘口举例 |
|------|------|---------|------------|
| 上半场 | 蓝 | 半场比分 + 进球详情 + 半场扩展 | BT1-1H / BT2-1H / BT6-1H / BT9 半全场（半场部分）/ 半场角球类 / 半场牌类 |
| 下半场 | 绿 | 下半场比分（前置：上半场已应用）；数据源开关=开时系统自动预填（全场−半场） | BT1-2H / BT2-2H / BT6-2H / BT24-30 / BT57 等 2H 派生类 |
| 15分钟段 | 紫 | 弹窗内 6 个时间段 Tab（0-15'/15-30'/30-45'/45-60'/60-75'/75-90'）独立应用 | BT48 / BT179 / BT180 |
| 全场扩展 | 绿（深） | 弹窗内 3 分区独立应用：全场累计扩展 / 加时赛（进入加时启用）/ 点球大战（进入点球启用） | BT1 / BT2 / BT3 / BT5 / BT7 / BT8 / BT158 / BT160 / BT161 等全场类 |

> 事件触发类（BT37 第 X 粒进球队伍 / BT159 角球第 X 粒 / BT6 赛中判输）无独立录入入口，依赖实时比分/进球明细自动驱动结算。

### 10.4 盘口卡片结构

每张盘口卡片含：
- **卡片头**：玩法名 + BT编号 + 盘口状态标签（开盘中/关盘/已结算/已取消）+ 注单数 + 投注额 + 操作按钮区（展开/收起、盘口结算、盘口取消、二次结算）
- **卡片体**：结算表格（详见 §10.5）
- **开盘中盘口**：卡片体只读展示「⏸ 等待关盘」，不提供结算操作；IM 推送关盘后才进入可结算状态；**关盘 = 绝对终态，无人工回退入口**

### 10.5 结算表格

**多线玩法**（如让球/大小）表头：盘口线 | 选项 | 赔率 | 注单数 | 投注额 | 结算结果 | 派彩额 | 操作。

**单线玩法**（如独赢/单双）表头：选项 | 赔率 | 注单数 | 投注额 | 结算结果 | 派彩额 | 操作。

**结算结果列**：下拉选择框，选项为「赢 / 输 / 退还 / 半赢 / 半输」等；系统按 L2/L3 规则预填时结算人员确认即可；L4 需全部手动选择；选择后派彩额实时计算。

**盘口卡片操作按钮**：

| 按钮 | 触发条件 | 功能 |
|------|---------|------|
| 结算（首次） | 盘口 = 关盘（待结算） | 触发首次结算确认弹窗 |
| 取消盘口 | 盘口 = 关盘（待结算）| 触发盘口取消弹窗（选择取消范围和原因）|
| 二次结算 | 盘口 = 已结算，且赛事在驳回窗口内 | 触发二次结算弹窗 |

### 10.6 多组基准分结算

含多条盘口线的玩法（如多线让球），每条线可能对应不同基准分组：
- **首次结算弹窗**：按组分区展示，结算人员按组逐一确认基准分和结算结果。
- **单组二次结算**：仅回退该组注单为待结算，其他组保持原结算结果（§二次结算单组粒度）；回退后该盘口线显示「部分待结算」状态，可点击重新进入首次结算弹窗处理。

## 十三、验收要点

| 编号 | 验证内容 | 预期结果 |
|------|----------|----------|
| 1 | ✓ 结算赛事按钮可点击条件 | 所有盘口均为已结算或已取消时方可点击；否则按钮置灰 |
| 2 | 驳回窗口超时后按钮显示 | 距最新结算时间 >24h 时「赛事驳回」按钮不显示 |
| 3 | 重新确认结算后驳回窗口滚动 | 重新结算后窗口重新计 24h |
| 4 | 腰斩操作无 IM 推送时 | Toast 提示「操作失败：未收到 IM 数据推送」，赛事状态不变 |
| 5 | 开盘中盘口不可操作 | 盘口状态为「开盘中」时只显示「⏸ 等待关盘」，所有结算按钮不显示 |
| 6 | L2 自动开关=关时 | 结算结果下拉已预填并高亮，结算人员确认后执行派彩 |
| 7 | L3 盘口未收到 IM 比分 | 赛果录入对应按钮高亮提示，补录比分后系统自动推算结果 |
| 8 | L4 小众玩法 | 结算结果下拉无预填，结算人员手动逐选项选择 |
| 9 | 多组基准分单组二次结算 | 仅目标组注单回退，其他组保持；该线显示「部分待结算」状态 |
| 10 | VAR 窗口期内结算操作 | 提示栏倒计时显示，系统不强制阻止，结算人员可自行决定是否继续 |
| 11 | 自动重结算聚合窗口结算人员主动点二次结算 | 立即终止聚合窗口，丢弃窗口期内中间态比分，按点击时最新比分结算 |
